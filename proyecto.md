# LifeTours

Aplicación móvil enfocada en la gestión y reserva digital de tours turísticos, diseñada para modernizar el proceso de contratación de servicios turísticos mediante una experiencia intuitiva, rápida y completamente digital.

## Descripción del Proyecto

**LifeTours** es una aplicación móvil desarrollada para una agencia de tours que permite a los usuarios explorar, reservar y administrar experiencias turísticas desde un dispositivo móvil.

El objetivo principal del proyecto es digitalizar el proceso de reserva, permitiendo que la interacción presencial quede fuera del sistema y facilitando una experiencia más cómoda tanto para clientes como para administradores.

La aplicación ofrece funcionalidades para usuarios generales y administradores, integrando autenticación, administración de tours y herramientas de interacción como favoritos y reseñas.

---

# Características Principales

## Funciones para Usuarios

* Registro e inicio de sesión.
* Exploración de tours disponibles.
* Visualización de información detallada:

  * Precio
  * Imagen representativa
  * Descripción del tour
* Reserva digital de tours.
* Gestión de tours reservados.
* Sistema de favoritos.
* Publicación de reseñas y opiniones.
* Interfaz móvil intuitiva y moderna.

---

## Funciones para Administradores

Los administradores cuentan con acceso a un panel de administración exclusivo que permite gestionar la información del sistema mediante operaciones CRUD.

### Funcionalidades del panel administrativo

* Crear tours.
* Editar tours.
* Eliminar tours.
* Gestionar usuarios.
* Administrar reservas.
* Administrar contenido relacionado con los tours.
* Control general de las tablas del sistema.

---

# Objetivo del Proyecto

Desarrollar una plataforma móvil que facilite la administración y reserva de tours turísticos de manera digital, mejorando la experiencia del usuario y optimizando la gestión interna de la agencia.
